# iTunes-style UI references

Screenshots of older iTunes (early–mid 2000s) used as visual references for the portfolio presentation app’s music-metaphor UI.

| File | Description |
|------|-------------|
| `itunes-windows-full-playback-sidebar.png` | Full window: playback controls, track info, left sidebar (Library, Store, Playlists), main album/track list, right Genius sidebar, bottom status bar. |
| `itunes-music-library-album-list.png` | Music library: brushed metal bars, grey sidebar, main content with album blocks (art + track list), column headers. |
| `itunes-source-pane-and-content.png` | Source list with blue selection; large content pane (banners, New Releases); footer controls and progress bar. |

See [portfolio-presentation-app-plan.md](../../portfolio-presentation-app-plan.md) for how these map to the planned layout (source list, main area, detail panel).
